# docs/

Docusaurus v3 documentation site with MDX compilation. All `.md` files are compiled as MDX, not plain markdown.

- **MDX treats `<` as JSX.** Never use bare angle brackets outside code fences. `<->`, `<path>`, `Promise<void>` in prose or tables will break compilation. Use Unicode arrows (`↔`, `→`, `←`), backtick-wrap inline code (`\`Promise<void>\``), or HTML entities (`&lt;`, `&gt;`).
- **Never modify `sidebars.ts` or `docusaurus.config.ts`** to add docs — autogenerated sidebars handle routing from directory structure.
- **Every `.md` file** needs `title:` frontmatter. Every new subdirectory needs `_category_.json`.
- **`README.md`** in any directory becomes the category index page.
- **`working/` docs** are excluded in production builds (`DOCUSAURUS_ENV=production`).
- Docs: `docs/docs/developer-docs/documentation-system.md` (site structure, adding pages, conventions).

See README.md for build commands and deployment.
