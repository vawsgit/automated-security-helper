# User Stories

As a user I would like to be able to scope activities to a project, so that related scans/results can be kept together

As a user I would like to be able to run a single ASH scan from the workbench
As a user I would like to be able to see the progress of an ash scan from the workbench
As a user I would like to be able to start/stop an ASH scan from the workbench

As a user I would like to be able to see a list of scans, including the in progress scan and prior ASH scans
As a user I would like to be able to see details on in progress or past scans

As a user I would like to be able to delete past scans and their related results/data

As a user I would like to be able to see findings from an ASH Scan

As a user I would like to be able to triage fundings todo/supress/wontfix (or some other appropriate status)
As a user I would like to have a view that shows me a cumulative list of findings that I have pending/fixed/supressed

As a user I would like to be able to examine findings and see:
- one or more filename, line number range, and code excerpt of the affected code
- An an explanation of the vulnerability and its attack vector
- Options for repair
- Supression recommendations, with justification
- Recommendation, supression, repair, defer
- This information can be augmented/enriched by AI

As a user I would like to be able to manage ASH Workbench settings
As a user I would like manage LLM model settings:
- Specifically these model settings must support Claude Anthropic models on bedrock.
