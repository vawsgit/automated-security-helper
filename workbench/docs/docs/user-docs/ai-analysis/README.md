# AI Analysis

ASH Workbench can analyze individual findings using Claude to provide explanations, risk assessments, suggested fixes, and references. AI analysis helps you understand the security impact of a finding and decide how to address it.

AI analysis is optional — it requires an AI provider (AWS Bedrock or Anthropic API) with access to a Claude model.

- [Setup](setup.md) — Configure your AI provider and settings
- [Analyzing Findings](analyzing-findings.md) — Run analysis and interpret results
