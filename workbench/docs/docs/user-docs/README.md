# ASH Workbench

ASH Workbench is a VS Code extension that brings the [Automated Security Helper (ASH)](https://github.com/awslabs/automated-security-helper) into your editor. Scan your code for security issues, review and triage findings, manage suppressions, and get AI-powered analysis — all without leaving VS Code.

## What you can do

- **Scan** any directory for security vulnerabilities using the ASH CLI
- **Review findings** in a filterable, sortable table with severity levels and code snippets
- **Triage findings** by marking them as Fix, Suppress, or Defer
- **Manage suppressions** through `.ash.yaml` rules with scoping, justification, and expiration
- **Analyze findings with AI** to get explanations, risk assessments, and suggested fixes
